# ToolHive — 免费在线工具站

## 怎么用（30 秒）

**双击桌面上的「ToolHive 网站」图标** —— 浏览器会自动打开 http://localhost:3000

- 想停止网站：关掉那个黑色命令行窗口即可
- 桌面图标不见了：在 E:\deepseek harness工作区\tool-hive\启动网站.bat 双击它

## 网站里有什么

6 个工具，全部在浏览器本地运行（不上传你的数据）：

| 工具 | 地址 |
|---|---|
| JSON 格式化 | /tools/json-formatter |
| 密码生成器 | /tools/password-generator |
| Base64 转换器 | /tools/base64-converter |
| 颜色选择器 | /tools/color-picker |
| 图片压缩 | /tools/image-compressor |
| CSV 转 JSON | /tools/csv-to-json |

英文为主，导航栏右上角可切换中文。
